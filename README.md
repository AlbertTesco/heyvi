# ХЭЙВИ

Демонстрационный сайт об ИИ-агентах, интеграциях 1С и CRM. Бриф скачивается на устройство.

[Открыть демо](https://alberttesco.github.io/heyvi/)

## Локальный запуск

```sh
python3 build.py
python3 -m http.server 8147 --bind 127.0.0.1 --directory dist
```

Откройте [локальный сайт](http://127.0.0.1:8147/). Для сборки нужен Python 3.12 или новее.

Тексты услуг заданы в `content.py`, разметка страниц находится в `build.py`, дизайн-токены — в `styles/tokens.json`.

## Обновление показа

После изменений пересоберите сайт, добавьте изменения в коммит и отправьте ветку `main`. GitHub Pages использует сборку из ветки `gh-pages`. Обновите её командой:

```sh
git subtree push --prefix dist origin gh-pages
```

После показов публикацию можно отключить в настройках Pages репозитория.
